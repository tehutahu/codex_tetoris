# 開発環境の運用

再現に必要なソース・設定・依存lockfile・テストはGitに保存します。作業用のコンピューターやクラウド環境だけに存在するファイルを完成条件に含めません。

Node 20.19以上の20系を使います。POSIX環境の初期セットアップは `bash scripts/codex-setup.sh`、Windows PowerShellでは `npm.cmd ci` を使います。起動・検証の全コマンドは [README](../README.md) が正本です。

PRのCIはクリーンなUbuntuで依存導入、実テスト、ビルド、依存監査、Chromiumによる受け入れ検証を実行します。ブラウザのインストールは検証用で、本番ゲームには含みません。

変更ごとに `codex/` ブランチとPRを作り、日本語で仕様の選択理由、検証コマンドと結果、未検証事項を記録します。ユーザーが指示した権限の範囲で、差分とCIを確認して統合します。実装Issueは受け入れ条件を満たしたPRのマージ後に完了させます。

認証情報や `.env` はコミットしません。デプロイは今回の対象外です。実ブラウザのChromiumでの確認は、実機のSafari・Firefox・タッチ操作の受け入れ確認を代替しません。
