# 実機受け入れの手順

自動テストの成功とは別に、Issue #30へ実機の証拠を残します。必須の実スマートフォンと実デスクトップのフォーカス確認が済むまでIssueを閉じません。

## 対象を固定する

対象コミットを `git rev-parse HEAD` で記録し、Node 20で `npm ci`、`npm test`、`npm run build` を実行してから `npm start` で配信します。PCとスマートフォンを同じネットワークにつなぎ、端末からPCのLANアドレスと配信ポート（既定3000）へ接続します。公開デプロイやファイアウォールの変更はこの手順に含めません。接続できない場合は結果として記録し、実機検証の代わりに扱いません。

例: `http://<PCのLANアドレス>:3000/?seed=acceptance-20`。OS、端末名、ブラウザ名と完全な版、対象コミット、URL、日時をIssue #30に記載します。スクリーンショットに個人情報を含めないようにしてください。

## スマートフォン

1. 縦向きで開始。左右を長押しし、指をボタン内で離すと反復が止まることを確認する。
2. 長押しした指をボタン外へ動かす。指を離す前でも反復が止まり、戻すだけでは再開しないことを確認する。
3. ソフトドロップを保持しながら別の指で回転する。2本目だけを離しても1本目の落下が続くこと、どちらも離すと止まることを確認する。
4. 回転とハードドロップを長押ししても1回だけ動くこと、通常の操作で意図しないページスクロールやズームが起きないことを確認する。
5. 着地後に横移動して位置を変えられること、ハードドロップは即固定することを確認する。
6. 指を保持したまま一時停止・アプリ切り替え・タブ切り替えを行う。復帰時は停止しており、再開後に古い保持入力・固定猶予・時計が飛ばないことを確認する。
7. 横向きに変え、横にはみ出さずボタン・盤面・記録欄を操作できることを確認する。縦にスクロールして全操作へ到達できることも確認する。
8. ゲームオーバーから同じ順番と新しい順番で再挑戦する。完走できる場合は20ライン達成・自己ベスト・リロード後の表示を確認する。達成できない場合はその項目を未確認と記録する。

## 実デスクトップのフォーカス

1. 実ウィンドウで開始し、キーを保持したままAlt+TabなどOSの操作で別ウィンドウへ移る。
2. 5秒以上待ち、戻る。自動停止し、時間が増えず、再開しても保持入力が勝手に動かないことを確認する。
3. 着地直後にも同じ手順を行い、再開時に残っていた固定猶予が保たれることを確認する。
4. 実際に別タブへ切り替えて同様に確認する。JavaScriptの明示blurイベントによるテストは、この証拠に代えない。

## 報告する内容

各操作の成功・失敗・未確認、再現手順、見えた挙動を記録します。Safariを対応範囲へ含める場合は実Safariが必要です。実機の結果が使えない場合は、自動検証のartifactとこの手順を残してIssue #30を開いたまま引き継ぎます。
